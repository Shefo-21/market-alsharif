إضافة وتعديل المنتجات من الموبايل — من أي مكان

🔒 لوحة الإدارة مقفولة

اكتب رمز الدخول (PIN) بتاعك.

أول مرة تفتح اللوحة على الجهاز ده هتثبّت PIN جديد. الـ PIN ده بيقفل الصفحة على جهازك بس، مش حماية سيرفر — لما توصل Supabase Auth أو تسجيل دخول الـ API هتبقى الحماية من السيرفر نفسه.

وضع القراءة فقط: المنتجات معروضة من الموقع الحي (Google Sheet) — الأقسام والأسعار ظاهرة. الإضافة والتعديل والحذف محتاجين مصدر كتابة متصل: وصّل Supabase من قسم الاتصال، أو شغّل سيرفر الـ API على جهازك.

الاتصال

لم يتم الاختبار بعد

لما ترفع الـ API أونلاين، حط رابطه هنا من موبايلك واحفظه — المتجر والإدارة هيشتغلوا عليه فوراً من غير تغيير كود. ولازم الـ API يسمح بالـ CORS لنطاق صفحة الإدارة.

البيانات دي بتتحفظ في متصفح جهازك بس، مش جوه الملف. وجدول Supabase لازم يكون فيه نفس أعمدة الـ API: id, name, category, price, oldPrice, badge, imageUrl, isActive.

➕ إضافة منتج جديد

الصورة بتتضغط تلقائياً على جهازك قبل الرفع (أقصى عرض 1000 بكسل). لو Supabase Storage متظبط، هتترفع عليه وتتحفظ كرابط؛ غير كده هتتحفظ جوه المنتج نفسه، أو تقدر تلزق رابط صورة يدوياً تحت.

المنتجات

لسه مفيش منتجات معروضة — احفظ الاتصال فوق الأول.

عشان الطلبات تتسجل على السيرفر كمان (مش واتساب بس)، لازم الـ API يبقى فيه Endpoint للطلبات، مثال: POST /api/Orders يستقبل كود الطلب والاسم والموبايل والمنتجات والإجمالي. رسالة واتساب دلوقتي فيها كود طلب تلقائي.
